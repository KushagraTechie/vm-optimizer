# Virtual Memory Optimizer

## Description
This project simulates different page replacement algorithms used in Operating Systems.

## Features
- FIFO Algorithm
- LRU Algorithm
- Optimal Algorithm
- GUI Interface using Tkinter
- Hit Ratio Calculation

## How to Run
1. Install Python
2. Run:
   python main.py

## Input Example
Pages: 7,0,1,2,0,3,0,4  
Frames: 3
